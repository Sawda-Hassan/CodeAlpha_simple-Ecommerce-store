# Simple E-Commerce Website

This is a simple e-commerce website built with **HTML**, **CSS**, and **JavaScript**.  
It displays products in a clean grid layout, allows users to view details, and manage a shopping cart (saved in `localStorage`).

🌐 **Live Demo:** [View Website](https://code-alpha-simple-ecommerce-store-i.vercel.app/)

---

## ✨ Features
- Responsive navigation bar with logo, pages, and cart count
- Product listing page with images, names, and prices
- Product detail pages with "Explore Now!" button
- Shopping cart page with add/remove functionality
- Checkout simulation (marks items as "Paid" without real payment integration)
- Clean styling using black, white, and yellow (`#f9e65c`) theme

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Storage:** Browser LocalStorage
- **Hosting:** [Vercel](https://vercel.com)
